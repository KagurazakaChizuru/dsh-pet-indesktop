## ⚠️ 升级说明

> **更正（2026-10-16，历史发布说明）**：本节首条与文末「发布前清单」第 5 条此前写作「无需迁移」「本版无配置迁移……产物可直接换回 v4.2.1」，两处都与事实不符——**「无需手动迁移」不等于「没有迁移」**：v4.3.0 首次启动会就地迁移数据；而**只把产物换回 v4.2.1 并不保证读得到迁移后的数据**。v4.3.0 的 GitHub Release 正文由本文件生成、**已发布，远端 Release 保持原样**，本次更正只落在仓库文件里；准确口径以本文件下方两条与 [`../README.md`](../README.md) 的「升级」「数据目录」两节为准。

- 直接覆盖安装或换用新版便携版即可；配置目录按变体独立，**无需手动迁移**——但**不是「没有迁移」**：首次启动 v4.3.0 会把主宠的每宠设置（位置、尺寸、角色、音效、气泡等）从 `config.json` 抽出写进 `config-slot-0.json`，并清掉 `config.json` 里的这些键（迁移前留一份 `config.json.pre-slot0-migration.bak`；目标档案已存在则绝不覆盖）。迁移在数据目录里**就地**发生，所以升级前请**备份整个数据目录**（数据目录按变体分、不按版本分）。
- 本版有几处会改变老用户观感的行为变更：
  1. **旧版右键菜单整体退役**：菜单文件/模板分发机制与配置键 `context_menu_template` 全部移除，旧值静默丢弃（不报错、不回退）；现代菜单树接管全部入口。
  2. **多进程多宠层退役**：`experimental_single_process_spawn` 配置键退役，单进程「单合成窗多宠」成为唯一架构；「直播捕获兼容」改为**重启级开关**——勾选后必须重启、多只桌宠会先收拢为主宠（活跃清单保留，取消勾选再重启即回来）。
  3. **Agent 联动减法**：`proactive_screen` 与 `agent_link` 各删掉一族旧配置键（卡住检测、行为模式、探索看门狗、事件汇报概率门等），老存档里这些值不再被读取。
  4. **免打扰期间语音也静音**：语音报时/节日语音此前只压气泡，现在一并静音（丢弃不补播）。
  5. **天气默认开、城市默认空**：不猜你的城市，首次点按走引导文案。
  6. **动画菜单点完叶子项自动收起**；随机动作按名字前缀分成 7 个家族，菜单高度约减半。
  7. **设置页改版**：页内标签、默认值小字与单项「改回默认」、搜索口语别名、页内跳转条；侧栏新增常驻「恢复默认设置」（二次确认，聊天密钥字段保留）。
- 新增持久配置键 20 个、退役 2 个；多数新键热读无需重启，例外项（直播捕获兼容等）在设置行上写明。

## 🚨 重要声明 / 已知问题

- **游戏帧率段（FPS）本版没有任何真实帧读数**：普通权限下采集后端起不了会话；授权方式是在设置页一次性把当前账户加入 `Performance Log Users` 组（一次 UAC），**需重新登录才生效**。未授权时段内如实显示原因，不填假数字。
- **macOS / Linux 的真实 GUI 未实机验收**（CI 三端均为无屏环境）；非 Windows 的逐像素输入穿透有若干路径只有替身证据。这两个平台请当「预览」对待。
- **HDR 截图**只在单显示器上做过真机验证；多屏 HDR 路径未验。
- **截图提取文字（OCR）已改为子进程执行**（用完即退，主进程内存零增长），代价是每次识别比进程内稳态**多约 1.8 秒**——这是刻意的取舍，不是退化。
- **直播捕获兼容模式下 OBS 仍可能黑屏**（Windows 分层窗口的既有约束），属预期行为，后续另案。
- **系统通知仍未接入系统原生弹窗**（与 v4.2.1 相同）：走应用自绘的右下角提示气泡。
- 安装包 / 安装器未签名（Windows SmartScreen、macOS Gatekeeper 需手动放行）；macOS 仅 Apple Silicon；Linux 仅 x86_64，建议 X11。

## ✨ 新内容

### 📸 截图提问（识屏 P0，#268）

右键菜单直接点「截图」→ 框选屏幕任意一块，松手出动作条：

- **提取文字**：本地 OCR 引擎随包携带（30 MB 模型），不联网、不上传；识别在子进程里跑，用完即退。
- **翻译**：走你配置的聊天模型，自动中英互译。
- **问问肥鱼**：带着截图直接和桌宠对话，可多轮追问；图片上云前有显式确认。
- **HDR 显示器截图不再发白雾**：HDR 屏上走专用通道（读 SDR 白点 → 抓 FP16 原始桌面 → 正确换算），截出来和眼睛看到的一样。
- 聊天输入框现在可以直接**粘贴 / 拖拽图片和文件**。

### 🤖 AI 对话五连（#247–#251）

- **Markdown 渲染**：表格、代码块、列表正常显示，复制按钮复制原文。
- **深度思考 + 联网搜索**：思考过程可见、随会话保存；联网档先检索再回答，引擎可换。
- **时间感知**：AI 知道现在几点、距上条消息隔了多久，提醒和寒暄不再穿越。
- 对话窗底部大片空白修复、重开自动回到最新回复。
- 切换会话不再递归崩溃、回答不再落错会话（#243）。

### 🏝️ 灵动岛

- **段化重设计**：信息槽改为段序列，时间与网速/帧率终于共存；第三方可以注册自己的岛段（声明式、四道护栏）。
- 视觉三批打磨：状态点五态、告警色滞回、软陶笔质感、声纳环。
- **游戏帧率段**（默认关）：基于官方 PresentMon 后端，设置页一次性授权。
- 贴边细条不再反复弹出收回（死区振荡修复）；岛碰撞改静态硬墙。

### 🎵 音乐与歌词

- **B 站 / 浏览器视频标题清洗**：网页视频也能正确出词（默认关，设置里开）。
- **foobar2000 窗口标题源** + 可配置格式串。
- 歌词取词不继承系统代理（VPN 用户不再整首无词）；右键「音乐 → 歌词对齐」五件套。
- **歌词采样提速**（#269）：采样链路改常驻事件循环，每拍开销 3.7 → 2.3 ms，循环反复新建/销毁带来的抖动消失。

### 🔔 提醒与语音

- **免打扰模式**：四档时长、暂存队列、全屏等效默认开；期间语音一并静音。
- 语音报时台词**每天整套换新**（不再永远同一句）。
- 语音通道排队家族收口：无声滞留、被顶播、旧结果盖新全修。

### 🖥️ 平台、性能与包体

- **非 Windows 逐像素输入穿透**：此前 Linux/macOS 上桌宠整屏吞点击（发布阻断级），已修。
- **直播捕获兼容模式**：让 OBS 能枚举到桌宠窗（重启级开关）。
- **帧序列 v3 统一档位**：素材磁盘占用 573.3 → 379.1 MB（−33.9%）。
- **内存瘦身**：单宠稳态 214.75 → 156.17 MB；停播 clip 池级回收；冷路径首帧不再阻塞界面。
- **设置窗打开提速**：中位 2238 → 1026 ms（−54%），点设置不再闪出一串无标题小窗（#261）。
